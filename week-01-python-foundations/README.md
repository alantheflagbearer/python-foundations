# Week 1: Python Foundations (Days 2–5)

The very first stretch of the roadmap — plain Python, no libraries beyond NumPy at the very end. These are short, hands-on practice scripts rather than full lessons with study guides; the paired-PDF workflow (concept guide + syntax walkthrough) starts later in the roadmap.

> **A note on day numbers here:** this repo's very first sessions were numbered informally as they were practiced, before the more careful day-by-day syllabus (see [`full_syllabus_days_1_365.md`](../full_syllabus_days_1_365.md)) existed. A few of these files' own internal comments don't line up 1:1 with that later syllabus's numbering. The headlines below describe what's actually in each file.

## Day 2 — Functions practice: averaging a list of scores
[`functions_day2.py`](functions_day2.py) — a first function, `calculate_average`, computing a mean from a list.

## Day 3 — Functions practice: a student grade report
[`functions_day3.py`](functions_day3.py) — `grade_report`, a function with a default argument (`passing_score=50`) that formats pass/fail output.

## Day 4 — Object-oriented programming: classes and methods
[`day4_oop.py`](day4_oop.py) — a `Dog` class with `__init__` and instance methods, the first OOP example in the series.

## Day 5 — Introduction to NumPy
[`day5_numpy.py`](day5_numpy.py) — first contact with `numpy`: arrays, vectorized math, and basic statistics.

## Study guide
[`day1_5_python_foundations_study_guide.pdf`](day1_5_python_foundations_study_guide.pdf) — a combined concept walkthrough covering this early stretch.
