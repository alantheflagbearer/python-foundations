real, honest finding: the prediction was wrong. T=40 trains to test_acc=0.995 -- and holds up even when the first spike must be carried 30-39 steps. Day 57's measurement wasn't false, it was measuring the wrong thing for THIS task: after training, sensitivity to a TINY nudge at x_0 actually DROPS (0.020786 -> 0.000021), while the effect of a full-size +3 spike at x_0 GROWS (0.132 -> 1.582). The network learned to ignore small noise and LATCH onto large spikes: 20% of its final hidden units sit pinned near tanh's +-1 limits, and Whh's largest eigenvalue (2.17) is above 1 -- which, with tanh bounding every unit, produces stable saturated memory states rather than explosion. A tiny-epsilon derivative is a LOCAL, linear measurement; latching is a large-signal, nonlinear effect it fundamentally cannot see. The caveat that matters for Day 59: this task is unusually latch-friendly (+-3 spikes over 0.3 noise, one binary fact to store). Vanishing gradients are real -- this task just happens to route around them.

class RNNClassifier(nn.Module):
    def __init__(self, hidden_dim=16, n_classes=2):
        super().__init__()
        self.rnn = nn.RNN(input_size=1, hidden_size=hidden_dim,
                          nonlinearity='tanh', batch_first=True)
        self.out = nn.Linear(hidden_dim, n_classes)

    def forward(self, x):              # x: (batch, T, 1)
        H, h_last = self.rnn(x)        # H: every hidden state, h_last: the final one
        return self.out(h_last[-1])    # many-to-one: classify from the last state
