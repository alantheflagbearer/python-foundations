Every result today is built on dL/dh_t. ======================================================================
5. WHAT DAY 60 TESTS
======================================================================
Two problems showed up at T=20, and they are not the same problem. Gradient reaching early timesteps VANISHES, so the dependency on x_0 is never learned. And the global gradient norm occasionally EXPLODES, jolting the weights. Gradient clipping -- capping the gradient's norm before each update -- is the standard fix for the second. Day 60 applies it to exactly Section 4's run and reports, honestly, what it does and doesn't fix.
